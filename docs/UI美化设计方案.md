## 一、设计目标与原则

NVCI Lite 是内网数据工作台，长期使用者是你自己。视觉目标按优先级：

1. **信息密度友好**：957 行表格、13 种状态、多个对话框——先保证扫读效率，再谈美观；
2. **品牌一致**：与 ALE 培训门户同源的紫色品牌体系，两个内部工具放在一起像一家人；
3. **状态语义靠颜色+形状双通道**：不只靠颜色区分（色弱可用），状态色全站统一映射。

三条铁律（源自 ALE 品牌规范）：

- 紫色只负责品牌与关键操作，不铺满页面；
- Logo 用原始文件，不加阴影/发光/渐变/变形，浅底彩色版、深底白色版；
- 橙色只做提醒、红色只做错误，均不大面积使用。

## 三、设计令牌（Design Tokens）

直接替换 styles.css 的 `:root`，与参考站同名同值，保证两站观感一致：

```css
:root {
  /* 品牌紫 */
  --ale-purple-700: #4f3478;   /* Hover、深色区块、当前步骤 */
  --ale-purple-600: #6b489d;   /* 主操作、链接、选中、主按钮 */
  --ale-purple-500: #7e5cb4;   /* 焦点环、次级强调 */
  --ale-purple-100: #f1ecf7;   /* 选中背景、标签底、悬停分区 */
  /* 功能色 */
  --ale-blue:   #0085ca;       /* 信息类：待核对、链接可访问、新建档 */
  --ale-teal:   #00b2a9;       /* 正向：有依据、有效未变、基线一致 */
  --ale-orange: #ff4500;       /* 提醒：厂商已更新、超出限制 */
  --ale-red:    #a50034;       /* 错误：不可达、无法解析、危险操作 */
  /* 中性墨色 */
  --ink-900: #1a1a1a;          /* 主文字 */
  --ink-700: #4b4d50;          /* 次文字 */
  --ink-500: #75787b;          /* 辅助文字、图标 */
  /* 面与线 */
  --surface: #ffffff;          /* 卡片/表格底 */
  --surface-soft: #f7f7f5;     /* 页面底、表头 */
  --line:      #d9d9d6;        /* 边框 */
  --line-soft: #e9e8e4;        /* 分隔线 */
  /* 圆角与阴影 */
  --radius-sm: 8px;  --radius-md: 12px;  --radius-lg: 20px;
  --shadow-sm: 0 1px 3px rgb(32 25 46 / 8%);
  --shadow-md: 0 10px 30px rgb(50 36 76 / 14%);
  /* 字体与版式 */
  --font-sans: "Trebuchet MS", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  --font-mono: ui-monospace, Consolas, monospace;   /* SHA-256、哈希、URL */

  /* 动效 */

  --motion-smooth: 200ms ease; /* 展开弹层 */

```

### 3.1 状态色全站统一映射（核心表，前端三处共用：芯片/徽章/铃铛）

| 状态 key | 中文短标签（芯片用） | 完整含义（悬停提示） | 色 | 备注 |
|---|---|---|---|---|
| valid_unchanged | 有效未变 | 内容与上次建档哈希一致 | teal | ● |
| baseline_matched | 基线一致 | 新建档，SHA-256 与 bundled 基线一致 | teal | ● |
| manual_ok | 人工确认有效 | 人工已裁定该资料有效 | teal | ● |
| new_archived | 新建档 | 首次建档（无基线可比） | blue | ○ |
| link_ok | 可访问 | 链接可达但未与历史比对，内容变化由完整校验确认 | blue | ○ |
| pending_review | 待核对 | 机器推测或来源冲突值，须人工核对 | blue | ○ |
| updated | 已更新 | 哈希与基线不一致，厂商可能已更新彩页 | orange | ▲ 竞对情报，最高关注 |
| too_large | 超限 | 下载内容超出大小限制 | orange | ▲ |
| vendor_throttled | 限流跳过 | 同品牌连续疑似限流，本轮跳过待重试 | ink-500 | — |
| paused / manual_invalid / manual_settled | 已裁定 | 人工裁定态，自动巡检跳过 | ink-500 | — |
| unreachable / redirect_broken / not_pdf / corrupt / network_error | 异常 | 不可达/跳转越界/非PDF/无法解析/网络异常 | red | ■ |

圆点/三角/方块前缀提供形状通道（色弱可辨）：● 正向 ○ 信息 ▲ 提醒 ■ 错误 — 中性。

## 五、组件级规范（逐个：现状 → 目标）

### 5.1 状态芯片（第 5 步核心交互，落实"点得动"）

**现状**：`probe-totals` 内纯展示徽章+数字，不可点；筛选靠下方下拉框。
**目标**：芯片即筛选器，删除状态下拉框（避免双控件）。

```text
┌──────────────────────────────────────────────────────────────┐
│ 全部 957 │ ● 有效未变 653 │ ● 基线一致 24 │ ▲ 已更新 10 │      │
│ ○ 待核对 0 │ ○ 可访问 2 │ ■ 异常 31 │ — 限流跳过 296 │   [?]  │
└──────────────────────────────────────────────────────────────┘
```

- 结构：短标签（3.1 表）+ 计数，`data-status` 驱动；
- 默认态：白底 1px --line、--radius-sm、色点 8px、文字 --ink-700、计数 --ink-500；
- 悬停：`transform: translateY(-1px)`、--shadow-sm、边框变所属状态色，cursor:pointer；
- **选中态**：状态色 10% 底（teal→#E6F7F5 / blue→#E5F3FA / orange→#FFEFE8 / red→#FBEAEE / gray→#EFEFEA）+ 2px 状态色边 + 计数加粗；再点取消；
- "全部"芯片：无筛选时呈选中态（紫 100 底 + 紫 600 边）；
- `[?]` 图例按钮：点开浮层逐条解释 13 种状态（3.1 表内容），首次访问自动展示一次；
- 计数为 0 的状态芯片降透明度 50% 且不可点；
- 筛选变化时表格与分页同步刷新（复用现有 renderProbeResults，改数据源为芯片状态）。

### 5.2 筛选与分页区（落实"靠上对齐"）

**现状**：状态下拉+搜索一行；"每页 20/共 N 条/页码"全在表格底部。
**目标**：

```text
┌──────────────────────────────────────────────────────────────┐
│ [🔍 搜索品牌/系列/文件…] ──────────────   每页 [20 ▾] 共 957 条 │   ← 与芯片区同层，右对齐
├──────────────────────────────────────────────────────────────┤
│ 状态 │ 品牌 │ 系列 │ HTTP │ 页数 │ 大小/SHA │ 检查时间 │ 备注 │ 操作 │ ← 表头 sticky
│ …表格体…                                                      │
├──────────────────────────────────────────────────────────────┤
│                          « ‹ 1 2 … 48 49 › »                  │   ← 仅页码留在表底
└──────────────────────────────────────────────────────────────┘
```

- 搜索框：高 40px、--radius-sm、聚焦 2px 紫 500 焦点环、内置 🔍 图标（padding-left 36px）；
- "每页"选择器与计数移到搜索行右端（用户建议项）；页码按钮组贴表格底居右；
- 页码按钮：32×32、--radius-sm、当前页紫 600 底白字、悬停紫边；禁用态透明度 35%。

### 5.3 结果表

- 表头：--surface-soft 底、--ink-700 加粗 13px、`position: sticky; top: 56px`（顶栏下）；
- 排序三角：默认 ⇅ 透明度 35%，激活 ▲/▼ 紫 600；可排序列悬停文字变紫；
- 行：内边距 10px 12px、行分隔 1px --line-soft（去掉现在的虚线）、悬停整行 --ale-purple-100 的 40% 透明度；
- 状态徽章：状态色 10% 底 + 状态色文字 + 圆点前缀（同 3.1），统一 12px/圆角 10px；
- 备注列：⚠/🔧/✍ 前缀保留；冲突候选等长文本截断 + title；
- 单元格批注指示（待核对）：蓝斜体值 + 右上角 6px 蓝点提示"有批注"；
- **当前轮次横条**（新增，表格上方 28px 高条）：
  `当前显示：09-06 05:13 · 定时 · 完整（957 条）   [× 恢复最新]`
  底 --ale-purple-100、左边 3px 紫 600 竖线；点历史"查看"时出现并滚动定位；"恢复最新"清除回最新一轮。

### 5.4 告警铃铛与面板

- 铃铛：有告警 → 徽标用 --ale-red（保持红），摇动动画保留但改为 2 次后静止（减少干扰）；
- 面板：--radius-md、--shadow-md、宽 440px；条目圆点按 3.1 映射（已更新=橙点、异常=红点）；
- **条目可点**：点击 → 关闭面板 → 跳转第 5 步 → 搜索框自动填入该品牌名（先做品牌级定位，资料行级定位二期）；
- 面板底部加"查看全部 →"跳第 5 步并按异常筛选。

### 5.5 按钮

| 类型 | 样式 | 尺寸 |
|---|---|---|
| primary | 紫 600 底白字，悬停紫 700，按下 translateY(1px) | 高 40px（对话框内 36px） |
| ghost | 白底 1px --line、--ink-700 字，悬停紫边紫字 | 同上 |
| danger | 白底红边红字（红底只用于确认场景），悬停红 10% 底 | 同上 |
| mini（行内） | 高 26px、12px 字 | — |

- 全部圆角 --radius-sm、`transition: var(--motion-fast)`、focus-visible 2px 紫 500 焦点环；
- 禁用态：透明度 45% + not-allowed。

### 5.6 进度条

- 轨道：--surface-soft、高 8px、--radius-sm；
- 填充：紫 600 → 紫 500 渐变；完成时切 teal；
- 文字行 13px --ink-500，进行中的型号名 --ink-700 加粗。

### 5.7 品牌树（第 1 步）

- 品牌行：悬停 --ale-purple-100 底；展开箭头旋转 90°（200ms）；

### 5.8 对话框（人工校验 / 批量导入）

- 遮罩：rgb(26 26 26 / 45%)；
- 容器：--radius-md、--shadow-md、宽 640/780，头部左侧 4px 紫 600 竖条 + 标题 15px 紫 700；
- 分区（dlg-sec）：--surface-soft 底 1px --line-soft，标题 13px 加粗 --ink-900；
- 结果区：成功 teal 左边条、失败 red 左边条、进行中 --ink-500；
- 文件选择：默认 input 隐藏，改为虚线拖放区（"点击或拖入 PDF"），选中后显示文件名+大小。

### 5.9 Toast 与空状态

- Toast：左侧 4px 状态色竖条 + 图标（✓/!/✕/ⓘ），--radius-sm、--shadow-md；
- 空状态：居中 64px 淡紫几何图形（网络节点线条风，非照片）+ 一句话 + 主操作按钮（如"建立第一轮哈希档案 →"直接触发全量校验）。

### 5.10 登录遮罩

深紫 700 → 紫 600 渐变底、白色 Logo 居中（高 40px）+ 白色 "NVCI Lite" 标题 + 半透明白输入框（白字）+ 白底紫字按钮。

## 七、交互动效

- 悬停上浮：translateY(-1px) + --shadow-sm，120ms；
- 弹层/对话框：opacity 0→1 + translateY(8px→0)，200ms；
- 铃铛摇动：触发时 2 个周期后停；
- 表格行高亮（历史查看定位）：--ale-purple-100 底闪烁 1.2s 渐隐；
- `prefers-reduced-motion` 时全部动效关闭。

## 八、可访问性要点

- 橙 #FF4500 白底对比度约 3.2:1——**只用于边框/图标/粗体大字**，正文级文字改用 #C2410C（4.6:1）；
- 状态 = 颜色 + 形状前缀（●○▲■—）双通道（3.1 已定义）；
- 所有交互件 focus-visible 焦点环（紫 500，2px，offset 2px）；
- 表头排序按钮加 `aria-sort`；芯片加 `aria-pressed`；铃铛面板 `role="dialog"` + Esc 关闭（已有）。

## 十、明确不做

- 全页紫色/大面积照片背景（工作台要保持素净，品牌照片素材留给门户类页面）；
- Logo 任何特效；紫色渐变按钮以外的渐变滥用；
- 移动端深度适配（桌面内网工具，仅保证 1024px 不破版）；
- 动画超过 200ms 的任何过渡。
