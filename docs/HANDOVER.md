## 1. 起因：这个项目为什么存在

网络工程师做跨品牌选型（交换机/无线 AP 等），要人工翻七八个厂商的官方彩页 PDF 抄参数，效率极低且容易抄错。本项目是 **NVCI 完整版**（github.com/apllozhang/NVCI，含 Source Configuration Guide 方法论，同作者）的轻量落地版：

- **四步向导**：选品牌型号 → 采集彩页 → 跨品牌勾选对比 → AI 分析出报告；第五步彩页校验用 SHA-256 哈希建档，守护约 989 条官方来源的长期有效性（来源失效/被替换能发现）。
- **合规底线（继承 NVCI，不可妥协）**：只访问已登记的官方 HTTPS 来源，域名白名单 + 受信重定向逐跳断言，PDF 签名 + SHA-256 双校验，声明 UA、顺序请求、不绕过登录/验证码/访问控制。
- **参数四态**：有值（原文引用已核验）/ 待复核（机器推测，须人工核对）/ 未披露（不代表不支持）/ 抽取失败。诚实标注不确定性是这个产品的灵魂，接手后任何改动都不许把"待复核"悄悄变成"有值"。

## 3. 专家意见：吸收了什么，还欠什么

- 已落地：认证加固、备份体系、路由拆分、可观测性（/metrics → vmagent → VictoriaMetrics → n9e）、CSP `script-src 'self'` 无内联脚本、六语言 i18n、翻译插件免疫（数据容器 `notranslate`）。
- **未落地（专家指出、确认有效、尚未排期）**：Word 叙事分析（analyzeWithAi）在超大参数矩阵上空返回，需要仿照参数抽取的分段方案（lib/ai.js 已有 SEGMENT_CHARS=28000 的抽取分段，叙事分析还没用上）。
- 用户原则：**达到专家要求，还要超越**。比如评审要求可恢复，交付的是"自动备份+轮转+脱敏+路径穿越防护"整套餐。

## 4. 已完成：当前能力基线

- 8 品牌 / 989 份官方彩页 profiles（34 个 profile 文件，含 category 字段），采集幂等可续传。
- 对比：跨品牌混选、品类漏斗、预带与反悔（cmpDropped 机制：第 3 步手动取消会压制第 1 步的自动预带）。
- 导出：Excel 参数对照（T05 型号分列）、Word 分析报告、AI 材料包。
- 工程化：121 个封闭单测（`npm test`，不碰网络）、无头验收脚本（scripts/ 下，puppeteer-core + Edge，几何断言而非截图目测）、`node deploy.js push` 一键部署 NAS（先自动备份）。
- 安全：登录限流（10 次/15 分钟/IP）、scrypt 口令、备份脱敏 apiKey、CSP、路径穿越防护。

## 6. 预期效果（北极星，别做偏）

一个**小白网络工程师不读文档、10 分钟内**完成"选品牌 → 采集 → 跨品牌对比 → AI 报告"，且每份资料可溯源（SHA-256 证据链）、每个参数诚实标注四态、来源失效自动发现。判断标准：新功能如果让界面更复杂、让用户需要理解内部概念才能操作，就是偏了；如果让"第一次用的人少一次犯错"，就是对的。

## 7. 如何接手（实操）

```bash
git clone https://github.com/apllozhang/nvci-lite.git && cd nvci-lite
npm install
npm test          # 121 个封闭测试，改任何东西之前先跑通它
npm start         # http://localhost:8788（口令见线下材料）
BASE_URL=http://10.20.30.203:8789 node scripts/bulk-select-e2e.js   # 无头验收样板
node deploy.js push   # 部署 NAS（自动先备份远端 data）
```

**目录导读**：server.js（装配）→ routes/（七模块）→ lib/（采集/解析/AI/安全，改逻辑主要在这）→ public/（app.js 单文件前端 + i18n.js 六语言）→ profiles/（彩页来源登记）→ scripts/（验收与治理脚本）→ test/（单测）。

**代码里的隐形约束（违反必返工）**：

- CSP 禁内联脚本，前端逻辑全在 app.js。
- 数据容器必须 `notranslate`/`translate="no"`（KISS-Translator 等翻译插件会改写数字导致对比错乱）。
- 列表行点击用"单一 handler + preventDefault + input.checked 同步"模式防双触发（label 包 input 会双触发，第 1/3 步都踩过）。
- 表格不做内滚盒子（560px max-height + sticky 会表头错位），对齐第 5 步彩页校验的模式。
- i18n 六语言（zh-CN/zh-TW/en/fr/es/ja）逐语言锚点插入，别用"找第一个锚点"的偷懒写法（曾整段插错位）。
- 第 1 步选择状态与 cmpSel/cmpDropped 的联动规则见 public/app.js 的 toggleDocSelect 注释，改选择逻辑必须保持三处一致。

**协作风格（用户对 AI 协作的要求，全文见线下材料"用户级协作军规快照"）**：需求不清主动问；意见不合一律直说、拿证据反驳；不编造事实，缺失信息标注"待确认"；交付后轻量引导（≤4 个方向），不抛任务山；敏感信息（IP/口令/密钥）不入公开仓库。
